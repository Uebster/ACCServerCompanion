Configuração Inicial: Pasta do Servidor

Como encontrar a pasta do servidor:

  1. Abra a sua Biblioteca Steam.
  2. Na busca, mude o filtro para incluir "Ferramentas".
  3. Procure por "Assetto Corsa Competizione Dedicated Server" e instale.
  4. Após a instalação, clique com o botão direito sobre ele, vá em "Gerenciar" e "Explorar arquivos locais".
  5. A pasta que abrir é a que você deve selecionar abaixo.

Comandos de Administrador

Para usar, entre no servidor, abra o chat (normalmente com a tecla 'Enter'), digite /admin <sua_senha_admin> e então use os comandos abaixo.

Controle de Sessão

  • /next — Pula para a próxima sessão.
  • /restart — Reinicia a sessão atual.
  • /manual entrylist — Cria um entrylist.json com os pilotos conectados.

Punições

  • /kick <núm do carro> — Expulsa o piloto do servidor.
  • /ban <núm do carro> — Bane o piloto até o servidor reiniciar.
  • /dq <núm do carro> — Desqualifica o carro.
  • /clear <núm do carro> — Remove penalidades pendentes do carro.
  • /clear_all — Remove todas as penalidades de todos os carros.
  • /tp5 <núm do carro> — Adiciona 5s de penalidade.
  • /tp15 <núm do carro> — Adiciona 15s de penalidade.
  • /dt <núm do carro> — Aplica um Drive-Through.
  • /sg10 <núm do carro> — Aplica um Stop&Go de 10s.
  • /sg20 <núm do carro> — Aplica um Stop&Go de 20s.
  • /sg30 <núm do carro> — Aplica um Stop&Go de 30s.
  • /tp5c <núm do carro> — Adiciona 5s (causar colisão).
  • /tp15c <núm do carro> — Adiciona 15s (causar colisão).
  • /dtc <núm do carro> — Aplica Drive-Through (causar colisão).

Debug e Status

  • /debug formation — Exibe status da volta de formação.
  • /debug bandwidth — Exibe o uso de banda do servidor.
  • /debug qos — Exibe a qualidade da conexão dos pilotos.

BoP em Tempo Real

  • /ballast <núm do carro> <kg> — Adiciona lastro ao carro (0-100kg).
  • /restrictor <núm do carro> <%> — Adiciona restritor de potência (0-20%).

Guia rápido para criar seu servidor

1. Rede e Servidor

Comece nas abas "Rede" e "Servidor" para definir o nome, senhas e configurações de conexão. Use os requisitos de SA e RC para controlar o acesso.

2. Pista e Sessões

Na aba "Evento", escolha a pista e use um modelo de sessões ou crie as suas (Treino, Qualy, Corrida). Ajuste o clima como desejar.

3. Regras do Jogo

Vá para a aba "Regras" para configurar pit stops obrigatórios, uso de pneus e outras regras de competição.

4. Configurações Avançadas

Na aba "Avançado", você pode forçar assistências, definir lastro (BoP) para carros ou criar uma lista de pilotos permitidos (entrylist).

5. Salve e Inicie

Use os botões "Salvar" para guardar suas configurações em arquivos. "Salvar Preset" salva o conjunto completo. Quando estiver pronto, clique em "START SERVER".

6. Administração

A aba "Admin" lista os comandos para gerenciar o servidor enquanto ele está no ar (ex: /next para pular a sessão).
